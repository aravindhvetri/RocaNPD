ROCA NPD — SPRINT 1 UNIT TEST CASES
===============================================================================
Document:     Sprint1_Unit_Test_Cases.txt
Location:     src/Documents/
Purpose:      Manual Excel import. Each SHEET section below should become
              a separate Excel worksheet.
Application:  ROCA NPD (SPFx)
Sprint scope: Sprint 1 — implemented NPD + Admin masters + Initiator submit
              through Vertical Head email only.
Button label: The form button is "SUBMIT REQUEST" (code). Treat "Send Request"
              as the same action.
Last updated: 18 September 2026
Verified against current source (not a runtime UAT run).

HOW TO LOAD INTO EXCEL
-------------------------------------------------------------------------------
1. Create a workbook with one sheet per SHEET name listed in the Cover sheet.
2. Copy the column header row, then one row per test case.
3. Suggested columns for every test sheet:
   Test Case ID | Title | Type | Priority | Preconditions | Test Steps |
   Expected Result | Test Data | Related Rule / Code
4. Status / Actual Result / Tester / Date can be added in Excel.

SPRINT 1 IN SCOPE
-------------------------------------------------------------------------------
- Login, role resolution, side navigation, unauthorized route
- Admin: Lookup Type, Lookup, Workflow Configuration, Brand Material Extension
- NPD lists: All Requests, Pending Approval, Approved Requests, Draft / ReWork
- NPD Form: Initiator create / Save Draft / Submit Request
- Submit email to Vertical Head (Approve / Re-work / Reject buttons)
- Common DataTable empty state, search, export, import, tab lock
- Common controls used by the above screens

SPRINT 1 OUT OF SCOPE (do not execute in this pack)
-------------------------------------------------------------------------------
- Vertical Head Approve / Rework / Reject on the form (after email)
- MIS Coordinator actions, Post to SAP
- Material Group module
- Reports
- SAP / Material Master integration

PASS/FAIL NOTE
-------------------------------------------------------------------------------
Expected results are taken from the current code and ProjectStandards
(R-NPD*, R-SEC*, R-C*). If a step fails, log the defect against the
Related Rule / Code column.
